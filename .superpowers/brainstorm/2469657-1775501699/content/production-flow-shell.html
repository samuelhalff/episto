3. Checkout as a real final step

Desktop checkout gets the same always-visible bottom action area as drafting, proper bottom breathing room, explicit pricing-loading CTA state, and full-width email entry.

What this solves

  • No preview pane flicker or reappearance on every step change
  • No clipped CTA labels in narrow buttons
  • No hidden payment action at the end of a long desktop scroll
  • Back navigation becomes deterministic and shared

What it requires

  • A deeper shared-shell pass across workspace, review, and checkout
  • Shared step/back-navigation helpers instead of page-local links
  • Careful Stripe/config handling so UI promises only what setup enables
